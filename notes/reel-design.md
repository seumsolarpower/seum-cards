# seum 릴스·카드 디자인 원칙

릴스(reel.mjs)와 카드(cards.mjs)를 만들거나 고칠 때 항상 이 순서로 확인한다.
사용자가 여러 번 고쳐서 확정한 규칙이다. 바꾸려면 사용자에게 먼저 묻는다.

## 1. 내용이 주인공, 인물은 리액션

- 화면 주인공은 **숫자·그래프·한 줄 문장**. 짤 인물이나 캐릭터는 예능 리액션처럼 작게 붙인다.
- 인물이 화면 절반 이상을 차지하면 안 된다 ("너무 인물 중심이라 이상하다", 2026-10-21).
- 기본 레이아웃 = **정보 보드 + 엿보기**: 흰 보드(위)에 내용, 리액션은 **왼쪽 아래**.

## 2. 저작권: 캐릭터 중심, 연예인 짤은 릴스당 1개까지

- 리액션 기본은 직접 그린 캐릭터 **세움이**(민트 찹쌀떡 몸 + 새싹, 큰 눈·볼터치). 표정: shock, happy (필요하면 추가).
- 예능 짤(유재석·박명수·하하만)은 **한 릴스에 1개까지**, 가장 웃긴 장면에만. 누끼(assets/jjal/cut)로 작게.
- 세움이는 매 장면 **같은 자리·같은 크기**, 등장할 때 통 튀는 움직임. 그래야 브랜드 자산이 된다.

## 3. 인스타 화면 안전 영역 (1080×1920)

- 위 220px, 아래 420px: 인스타 UI 자리, 글 금지.
- **오른쪽 x 930 이상, y 1000~1700**: 좋아요·댓글·공유 버튼 자리. 리액션·말풍선·숫자를 두지 않는다.
- 프로필 그리드는 3:4로 잘린다. 숫자와 핵심 문장은 **y 240~1680** 안에.

## 4. 첫 1초 훅

- 첫 장면은 움직이는 숫자 하나로 시작: **카운트업**(예: 144 → 166만원).
- 검정 화면에 글만 있는 훅 장면은 쓰지 않는다 (사용자가 뺌).

## 5. 장면당 글 요소 3개까지

- 한 장면 = **문장 한 줄 + 숫자(또는 그래프) + 리액션(말풍선 한마디 또는 짤 자막)**.
- 태그 알약, 회색 보조 설명, "현재 심정" 라벨 같은 겹 요소는 넣지 않는다. 필요한 정보는 다음 장면이나 캡션으로.

## 6. 그래프는 해석까지

- 막대는 0부터, 높이는 값에 비례 (차이를 과장하지 않는다).
- 차이는 공중에 뜬 배지가 아니라 **괄호로 두 막대 높이 차를 직접 가리킨다**.
- 체감 단위로 바꾼 한 줄을 문장으로 쓴다 (예: 월 +22만원 → "1년이면 264만원 더 낸다").
- 없는 중간 값을 지어내지 않는다. 확인된 점만 그린다. 출처는 작게 표기.

## 7. 말투: 세움이가 말하듯

- 설명문("월세가 이만큼 올랐다") 대신 짧은 구어("월세 또 올랐대…").
- 말풍선은 12자 안팎. 짤 자막은 28자 이내.

## 8. 끝 장면은 저장 CTA

- 세움이가 "저장해 두고 ~때 꺼내 보기"를 가리키며 끝낸다. 로고 `seum.`.

## 고정 규칙 (기존)

- 색: 검정·흰색·민트(#1fd8a4) 1색. 세움이 볼터치 분홍만 예외.
- 글꼴: Pretendard 하나.
- 형광펜(mk)은 장면·카드당 1곳. 숫자는 한 장에 큰 숫자 하나.
- 색 박스·3D 자막·이모지 스티커 금지 ("짜깁기/올드").
- 카드에 아이디·"투자 권유 아님" 문구 넣지 않음.
- 짤 뜻과 뉴스 문맥을 맞춘다.
- 사진은 PD/CC0/CC BY, 사람 사진은 젊고 밝은 생활 사진, 출처 표기.
